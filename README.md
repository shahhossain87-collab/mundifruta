# MUNDIFRUTA — new layout

This branch is the new shop website. It is not live.

- Live site: https://mundifruta.com
- Live code: branch `master` (static HTML, GitHub Pages)
- This code: branch `new-layout` only
- Do not merge this branch into `master`. That would replace the live site with an app GitHub Pages cannot run.

Stack: TanStack Start, React, Vite, TypeScript, Tailwind. Product data is in `src/data/catalog.json`. Photos are in `public/fotos/`.

Install and run: `npm install`, then `npm run dev`.

Pickup only. No delivery. Checkout is a WhatsApp message. Do not invent prices.
